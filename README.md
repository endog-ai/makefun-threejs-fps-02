EMBERLINE is a three.js tactical FPS set in a foundry/power-plant yard at dusk. Attackers plant the Molten Core bomb at Turbine Hall or Coal Yard while defenders hold the sites; first to 5 rounds wins. Bots move, see and shoot back; buy menu and round economy, grenades, headshot bonus damage, and a molten Crucible pit at mid that vents steam on a cycle. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
npx --yes serve game
# then open http://localhost:3000 in desktop Chrome
```
